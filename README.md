# Card Room

Practise 6-max no-limit hold'em against bots that play like real people. Single player, runs entirely in the browser, no accounts, no server, no real money. Installable on iPhone as a home-screen app.

## Run it

```bash
npm install
npm run dev        # play at http://localhost:5173
npm test           # engine + bot tests
npm run build      # static site in dist/
```

**On your iPhone:** deploy `dist/` anywhere static (Netlify drop, Cloudflare Pages, GitHub Pages), open it in Safari, then Share → Add to Home Screen. It runs full-screen and keeps working offline. Progress is saved in the browser's local storage.

## How the bots work

No language models. Each bot runs the same engine, tuned by a personality profile (`src/bots/profiles.ts`):

| Style | Target VPIP / PFR | How it plays |
| --- | --- | --- |
| Nit | 13 / 10 | Very few hands, folds to pressure, rarely bluffs |
| Solid regular | 23 / 19 | Tight-aggressive, positional, balanced |
| Loose-aggressive | 33 / 26 | Lots of hands, lots of pressure |
| Calling station | 46 / 8 | Limps and calls too much, pays off |
| Maniac | 55 / 40 | Raises everything, bluffs big, tilts |

**Preflop** (`brain.ts`): every hand class is ranked (`preflopTable.ts`, generated by `scripts/genPreflop.ts` from heads-up and 4-way equity plus a playability bonus for pairs and suited connectors). Bots open, limp, 3-bet, call or fold by position, raise size, stack depth, and how wide they believe the raiser is.

**Postflop**: bots estimate each opponent's range from their preflop action and their observed stats (VPIP, PFR, 3-bet %, aggression — including yours), then narrow it for postflop bets and raises. They run a Monte Carlo simulation against those ranges and compare equity to pot odds, adjusted for draws, board texture, the number of opponents and their personality (bluffing, stickiness, sizing, slowplaying).

**Realism**: decisions use mixed frequencies rather than fixed thresholds, bots take human-like time to act, rebuy when short, and the tilt-prone ones loosen up after losing a big pot.

Check the styles still hold after changing a profile:

```bash
npm run simulate -- 6000   # bot-only session: VPIP/PFR/3-bet/AF/WTSD/win rate per style
npx tsx scripts/bigpots.ts # the biggest pots with each bot's reasoning
```

## Practice features

- Pot odds shown when you face a bet (toggle in settings)
- Hand history with every player's hole cards and each bot's reasoning and equity
- Session stats for you and each bot (VPIP, PFR, 3-bet, AF, WTSD, BB/100)
- Optional labels showing each bot's style

## Layout

```
src/engine/   cards, 7-card evaluator, betting rules, side pots
src/bots/     preflop table, range-aware equity, decision logic, profiles, stats
src/session.ts  table session: dealing, rebuys, tilt, stats
src/store/    local storage: session, prefs, hand history
src/ui/       React UI
scripts/      table generation and simulations
tests/        vitest
```
